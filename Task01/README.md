# Task01

Лабораторная работа №1. Данные — датасет MovieLens (ratings, movies и т.д.).

## Файлы в папке

- ratings.csv — оценки пользователей (userId, movieId, rating, timestamp)
- movies.csv — фильмы (movieId, title, genres)
- tags.csv — теги пользователей
- users.txt — пользователи
- occupation.txt — список профессий
- genres.txt — список жанров

## Что сделал сам

- ratings_count.txt — посчитал минимальный и максимальный userId из ratings.csv и сколько раз каждый из них встречается. Формат: <userId> <количество>.
- sqlite.txt — версия установленного SQLite и список режимов вывода sqlite3.
